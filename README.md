# fullstack_developer_capstone

## Project Name
fullstack_developer_capstone

## Repository Name
xrwvm-fullstack_developer_capstone

## Overview
This full-stack car dealership application allows users to browse dealerships across different states, view detailed customer reviews, register and log in to submit new dealership reviews, and filter services dynamically. Built using Django, React, Express, MongoDB, and deployed using Docker/Kubernetes CI/CD pipelines.
